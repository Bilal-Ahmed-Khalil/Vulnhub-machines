# Pentest Reports – Vulnerable Machines Lab

## Overview
This repository contains structured penetration testing reports for multiple intentionally vulnerable machines.  
The goal is to document methodologies, findings, and remediation steps in a reproducible format for cybersecurity learning and research.

## Contents
- **Machine Profiles**: Brief description of each vulnerable VM (OS, services, purpose).
- **Attack Vectors**: Exploitation paths identified (network, web, privilege escalation).
- **Tools Used**: Open‑source utilities (Nmap, Burp Suite, Metasploit, Gobuster, etc.).
- **Findings**: Credentials, misconfigurations, vulnerabilities exploited.
- **Remediation**: Recommended fixes and hardening steps.
- **Lessons Learned**: Key takeaways for future engagements.


Each report includes:
1. **Reconnaissance** – Enumeration results  
2. **Exploitation** – Steps taken to gain access  
3. **Post‑Exploitation** – Privilege escalation, persistence, data access  
4. **Mitigation** – Suggested defensive measures  

## Disclaimer
These reports are based on **lab environments only** and are intended for **educational and research purposes**.  
Do not use these techniques on systems without explicit authorization.
